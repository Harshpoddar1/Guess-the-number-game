# 🎯 Guess the Number

A simple browser game where the computer picks a secret number and you try to guess it. After every guess you get a hint — too high or too low — until you find the answer.

Built with **HTML, CSS and JavaScript**.

## 🎮 How to Play

1. The computer picks a random number (default range: 1–100).
2. Type your guess in the input box and submit.
3. You get a hint: **too high**, **too low**, or **correct**.
4. Keep guessing until you win.

## ✨ Features

- Random number generated with `Math.random()`
- Instant hint after each guess
- Input validation (only valid numbers)
- Simple, clean UI

## 🛠️ Tech Stack

| Part | Used for |
|------|----------|
| HTML | Input box, button, result area |
| CSS | Styling and layout |
| JavaScript | Random number, comparing guesses, showing hints |
